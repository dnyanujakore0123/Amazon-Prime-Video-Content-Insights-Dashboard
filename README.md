# Amazon-Prime-Video-Content-Insights-Dashboard
This dashboard analyzes Amazon Prime Video content to uncover insights about genres, ratings, release trends, and geographical distribution of shows and movies.

🔹 Tools Used

Power BI

Power Query

DAX

🔹 Key Insights

Total shows: 9687.

Majority content is Movies (~80%) vs TV Shows (~20%).

Most popular genres include Drama, Comedy, and Documentary.

Significant growth in content release after 2000.

Content is widely distributed across countries like India, USA, UK, Canada

🔹 Features

Genre-based analysis

Country-wise content distribution (Map visualization)

Year-wise release trend analysis

Rating distribution insights

Interactive filtering by country
